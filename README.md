# MathSymbolic

Symbolic mathematics (computer algebra) for [MathCraft](https://github.com/ACSquaredS/MathCraft), an open-source, MATLAB-inspired numerical computing environment.

> **Status:** Early stage. The repository is set up; implementation has not started.

## Role in MathCraft

MathSymbolic works on expressions as data instead of numbers. It handles exact manipulation and hands results to the numerical modules when a number is needed.

## Depends on

- [MathCore](https://github.com/ACSquaredS/MathCore)

## Planned scope

- Expression tree and a parser for symbolic input
- Simplification and expansion
- Differentiation and integration of elementary functions
- Equation solving
- Conversion of a symbolic expression into a function that [MathNumerical](https://github.com/ACSquaredS/MathNumerical) can evaluate

## Boundaries

Floating-point evaluation and numerical algorithms belong in MathNumerical.
